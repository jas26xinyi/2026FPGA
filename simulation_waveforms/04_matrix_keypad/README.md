# 04 矩阵键盘扫描与消抖

![Vivado 仿真波形](tb_keypad_scanner.png)

## 波形判读

- `col_n` 按 `1110→1101→1011→0111` 循环，低电平列选通；按键使相应 `row_n` 位从 `1→0`。
- 稳定按下跨过规定扫描次数后，某个 `clk` 上升沿产生单周期 `event_valid: 0→1→0`，同时 `event_code` 给出键值，`events` 加一。
- 长按期间扫描继续，但不会产生第二个有效脉冲；松开使行线 `0→1`，完成释放消抖后才能接受下一键。
- `pressed_keys` 同时含多个有效位时，不输出 `event_valid`；`scenario=0x10~0x1F` 依次覆盖 16 个物理键位。

## 实际功能

验证四列轮询、16 键映射、按下/释放消抖、长按单次上报和多键冲突屏蔽。
