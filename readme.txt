下面要进行FPGA（数字系统课程设计）的方案设计和工程文件设计及调试交付，请按照下面的步骤完成任务交付：
1、阅读“课件”文件夹，学习基本的语法结构设计，之后的框架架构及语法要按照这个文件夹里的来。（可生成阅读理解后的md文件放在根目录，方便后续直接写文件代码时调用）
2、阅读“技术文档及例程”文件夹，里面有开发板文件夹，为本次使用的Xilinx FPGA板，要严格按照技术文档来，之后全部调试都是基于这个板子。
3、本次题目为“数字系统课程设计-题目新.docx"文件中的题目，仔细阅读题目要完成所有的要求。同时为满足“其他功能和设计大家可自行发挥，鼓励调用更多其他外设实现更复杂的系统设计。”的要求，我们在密码锁控制器的所有基础功能的基础上，加上了两个功能，需要你一起并入系统设计：1、密码输入使用矩形键盘输入（参考“技术文档及历程”文件夹的矩形键盘文件夹，里有工程文件案例可以参考或者复用）；2、在“若密码错误，将提示密码错误，要求重新输入，四次输入都错误，将发出报警信号。”功能的基础上平行增加同时的摄像机拍照功能：摄像头型号为ov5640。在触发报警条件后截取4帧，然后在fpga外接的hdmi显示屏显示截取的图像。
4、本机运行程序环境为D盘：Vivado2023.2,DocNav,Vitis HLS2023.2,Vitis Model Composer2023.2，需要你完成接开发板前所有的调试工作，保证接线后可以直接正常运行。确认调试无误后将根目录下的所有交付文件上传至GitHub远端仓库https://github.com/jas26xinyi/2026FPGA.git
5、完成交付后，在根目录下编写使用手册，即对照开发板技术文档给出详细接线，调试和各按键调试使用流程
