# FPGA 密码锁实机验证报告

## 验证环境

- 开发板：HX7A75A，器件 `xc7a75tfgg484-2`
- 工具：Vivado 2023.2
- 默认构建参数：`ENABLE_CAMERA=0`
- 输入设备：连接至 J2 的 4×4 矩阵键盘
- 下载方式：JTAG 下载 `password_lock_top.bit`

## 已通过项目

| 项目 | 实测结果 |
|---|---|
| 上电初始化 | 正常进入 `PASS` 等待状态 |
| 数码管 | 位选、段码和状态文字显示正确 |
| 矩阵键盘 | 调整 FPGA 行列管脚角色后，16 键映射正确 |
| SW1 输入启动 | 低到高拨动后进入密码输入状态 |
| 默认密码 | `1234` 可正常进入 `OPEN` |
| 输入编辑 | 数字输入、`B` 退格、`C` 取消和不足四位确认均正确 |
| 8 秒超时 | 未开锁且无操作时回到 `PASS` |
| 16 秒超时 | `OPEN` 后无操作自动上锁并回到 `PASS` |
| 错误计数 | 依次显示 `Err1`、`Err2`、`Err3`，第四次进入 `ALAr` |
| 报警解除 | 报警时矩阵键盘无权解除，仅 KEY2 有效 |
| 解除后计数 | KEY2 后重新输入，下一次错误从 `Err1` 开始 |
| 解除后输入 | KEY2 后直接恢复新一轮输入，无需重新拨动 SW1 |
| 报警显示 | LED4 按约 2 Hz 节拍闪烁 |
| 蜂鸣器 | 当前实板 P20 为高电平使能，间歇报警音正常 |
| 管理员改密 | KEY1、`SEt`、四位密码、`A`、`SAVE` 流程正常 |
| 新旧密码切换 | 新密码 `2580` 生效，旧密码 `1234` 被拒绝 |
| Flash 复位恢复 | KEY4 复位后仍可使用 `2580` |
| Flash 掉电保持 | 断电 5 秒、重新上电并下载同一程序后，`2580` 仍可开锁 |

## 实测中修正的问题

- 数码管位选改为共阳低有效，并按板卡实际位序修正约束。
- 矩阵键盘接线呈转置关系，通过交换 FPGA 行/列端口角色修正，不要求重新接线。
- 管理员解除报警时清零错误次数，避免出现 `Err5` 至 `Err7`。
- KEY2 解除报警后直接进入新输入会话，同时复位键盘扫描器。
- 蜂鸣器极性以当前实板为准改为高电平使能；旧版手册的低电平说明不适用于当前板卡。
- 当前实板操作方向确认：SW1 拨上后可进入工作状态并使用 KEY1 进入 `SEt`；SW5 拨上后蜂鸣器通路接通。
- W25Q64 的连续 SPI 指令之间加入安全的片选高电平间隔；修正后写入、回读、复位恢复和掉电保持均通过。

## 尚未进行的硬件验证

摄像头功能当前由 `ENABLE_CAMERA=0` 关闭，OV5640 未连接；HDMI 显示器也未连接。因此摄像头初始化、四帧抓取、BRAM 四宫格和 HDMI 输出仅保留设计与仿真结果，不标记为实机通过。

## 当前板上密码

实机验证结束时，W25Q64 中保存的管理员密码为 `2580`。如需恢复为 `1234`，按 KEY1 进入 `SEt`，输入 `1234` 后按 `A`，等待 `SAVE` 返回 `PASS`。
