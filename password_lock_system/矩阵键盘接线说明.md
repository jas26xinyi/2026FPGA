# 4×4 矩阵键盘接线说明（摄像头关闭版）

当前工程默认参数为 `ENABLE_CAMERA=0`，无需连接 OV5640。矩阵键盘是无源触点，通常只需 8 根行列线，不接 3.3 V，也不接 GND。

## 当前实机接线（无需改线）

当前键盘实测出现了主对角线正确、其余按键互为转置的现象，因此工程已在 XDC 中交换行列角色。保持现有 8 针排线不动即可，当前对应关系如下。

| 矩阵键盘 | 板卡 J2 信号 | FPGA 管脚 | 工程端口 |
|---|---|---|---|
| C1（第一列：1、4、7、*） | P2IO[0] | T3 | `keypad_col_n[0]` |
| C2（第二列：2、5、8、0） | P2IO[1] | T1 | `keypad_col_n[1]` |
| C3（第三列：3、6、9、#） | P2IO[2] | U1 | `keypad_col_n[2]` |
| C4（第四列：A、B、C、D） | P2IO[3] | U2 | `keypad_col_n[3]` |
| R1（第一行：1、2、3、A） | P2IO[4] | V2 | `keypad_row_n[0]` |
| R2（第二行：4、5、6、B） | P2IO[5] | R3 | `keypad_row_n[1]` |
| R3（第三行：7、8、9、C） | P2IO[6] | R2 | `keypad_row_n[2]` |
| R4（第四行：*、0、#、D） | P2IO[7] | W2 | `keypad_row_n[3]` |

工程中的键值布局为：

```text
1  2  3  A
4  5  6  B
7  8  9  C
*  0  #  D
```

- `0～9`：密码数字。
- `A`：确认。
- `B`：退格。
- `C`：取消。
- `*`、`#`、`D`：当前保留（扫描码分别为 E、F、D）。

若以后更换键盘模块，应重新核对模块排针的 R/C 丝印；不同厂家的 8 针排针次序可能不同。

## 摄像头参数开关

顶层 `password_lock_top` 的参数 `ENABLE_CAMERA` 默认为 `0`：摄像头初始化、PCLK 跨时钟采集和四帧 BRAM 均不会被实例化，XCLK 保持低电平，PWDN 保持高电平，RESET_N 保持低电平，SDA 释放为高阻态。

以后接好 OV5640 后，可用下面的命令构建摄像头版：

```powershell
.\password_lock_system\scripts\run_all.ps1 -EnableCamera
```

普通矩阵键盘阶段直接运行（不加开关）即可：

```powershell
.\password_lock_system\scripts\run_all.ps1
```
