# FPGA 密码锁系统使用手册

## 工程与下载

目标器件为 HX7A75A（`xc7a75tfgg484-2`），Vivado 2023.2 工程位于 `vivado/password_lock_system.xpr`。可直接下载 `password_lock_top.bit`；重新构建时在 Vivado Tcl Console 执行 `source scripts/build_all.tcl`。

当前顶层参数 `ENABLE_RPI_CAMERA=1`，启用树莓派报警 UART；设为 0 可综合出不含该链路的纯密码锁版本。矩阵键盘、数码管、板载按键/开关、LED、蜂鸣器及 W25Q64 的原有功能已完成实机验证；新增 KEY3 临时密码已通过 RTL 仿真，仍需下载新版位流进行实机复测。CSI 相机和 HDMI 由 Raspberry Pi 5 负责，新链路尚待整机联调。

## 外设接线

使用工程自带 `constraints/password_lock_system.xdc`，不要再叠加通用 IO 约束。

| 外设 | 信号 |
|---|---|
| 系统时钟 | `Y18`，50 MHz |
| J2 矩阵键盘行输入 | `V2,R3,R2,W2`（P2IO[4:7]） |
| J2 矩阵键盘列输出 | `T3,T1,U1,U2`（P2IO[0:3]） |
| W25Q64 | CS `M20`、HOLD `K13`、MISO `M13`、SCLK `K14`、WP `K17`、MOSI `L13` |
| 树莓派 UART TX | GPIOA_0，扩展口脚 1，FPGA `J16`，接 Pi GPIO15/RXD0 物理脚 10 |
| 树莓派 UART RX | GPIOA_1，扩展口脚 2，FPGA `H13`，接 Pi GPIO14/TXD0 物理脚 8 |
| 树莓派公共地 | FPGA 扩展口脚 12 或 30，接 Pi GND 物理脚 6 |

矩阵键盘的逐线对应关系见 `矩阵键盘接线说明.md`。键盘是无源触点，只接 R1～R4 和 C1～C4，不接电源与地。树莓派连接必须交叉 TX/RX 并连接公共地；两块板各自供电，不连接 3.3V 或 5V 电源脚。CSI 排线和显示器只连接树莓派。当前实板应将 SW5 拨上以接通蜂鸣器，数码管使用 SW6 档位。当前实板已确认 P20 蜂鸣器为高电平使能，与旧版开发板手册中的低电平描述不同，工程以实测极性为准。

树莓派 UART 默认启用。暂不使用树莓派时无需拆改密码锁逻辑，UART TX 只会保持空闲高电平；若希望在综合时完全移除该模块，运行 `scripts/run_all.ps1 -DisableRaspberryPiCamera`，它会把 `ENABLE_RPI_CAMERA=0` 传给顶层。

## 操作流程

默认密码为 `1234`。拨动 SW1 产生上升沿进入输入，数字键输入密码，`A` 确认，`B` 退格，`C` 取消。输入不足四位或超过四位时不会误确认。未开锁状态连续 8 秒无操作自动返回待机；开锁后 16 秒无操作自动上锁，开锁期间按 `A` 也可立即上锁。

临时访客密码：在数码管显示 `PASS` 时按 KEY3，系统立即生成一组四位伪随机密码，数码管左侧显示 `tEMP`、右侧显示该密码。按 SW1 可直接进入输入页面，固定密码和当前临时密码都可开锁。停留 8 秒无操作或按矩阵键盘 `A`/`C` 会返回 `PASS`，但临时密码仍然有效。再次在 `PASS` 或 `tEMP` 页面按 KEY3 会生成并显示一组不同的新密码，上一临时密码立即失效。临时密码不会写入 W25Q64；按 KEY4 复位、重新配置 FPGA 或断电后失效，而固定密码保持不变。

KEY3 在密码输入、固定密码设置/保存、错误提示和报警状态下不会改变临时密码，避免打断原有流程。报警仍只能使用 KEY2 解除。这里的随机密码由 FPGA 内部自由运行 LFSR 采样生成，适合课程设计的临时访客用途，不应视为密码学真随机密码。

连续输错三次会短暂显示 `Err1`、`Err2`、`Err3` 并允许重试；第四次错误立即进入 `ALAr`，报警 LED 以约 2 Hz 闪烁，蜂鸣器输出约 2 kHz 音调并同步间歇鸣叫，同时通过 UART 向树莓派发送 `ALARM`。树莓派回 ACK 后连续抓拍四张图并在自身 HDMI 上显示四宫格。报警状态只有板载 KEY2 能解除，矩阵键盘和其它按键均不能停警。管理员按 KEY2 处理报警后，错误次数清零、矩阵键盘扫描器复位，并直接开始新的四次输入机会，无需重新拨动 SW1。8 秒无操作后仍会按题目要求回到等待。解除报警不会取消已触发的拍照，也不会清除树莓派上的四宫格。

管理员改密：先将 SW1 拨上进入工作状态，再按 KEY1 进入 `SEt`，输入四位新密码后按 `A`。系统完成 W25Q64 擦除、写入和回读校验后才启用新密码；失败时保留旧密码并显示 `FErr`。两份日志记录支持掉电恢复，均无效时回退 `1234`。

数码管右侧显示输入数字，左侧显示 `PASS`、`SEt`、`ErrN`、`OPEN`、`ALAr`、`SAVE` 或 `FErr` 等状态；LED 分别表示就绪、输入、开锁和报警/故障。

## 验证边界

`sim/` 下提供锁控制器、临时密码生成器、报警蜂鸣器、树莓派 UART 报警协议、键盘扫描、数码管和 W25Q64 日志模型测试。Vivado 批处理在 Windows 上可能在测试 `$finish` 后停留数十秒，这是 XSim 2023.2 的退出行为，不代表测试失败；以日志中的 `PASS tb_*` 为准。已完成的实机项目和仍待验证的 KEY3、树莓派相机链路边界见 `实机验证报告.md`。树莓派的详细配置与测试方法见 `../raspberry_pi5_camera/README.md`。
