# FPGA 密码锁系统使用手册

## 工程与下载

目标器件为 HX7A75A（`xc7a75tfgg484-2`），Vivado 2023.2 工程位于 `vivado/password_lock_system.xpr`。可直接下载 `password_lock_top.bit`；重新构建时在 Vivado Tcl Console 执行 `source scripts/build_all.tcl`。

当前默认构建为矩阵键盘优先版，顶层参数 `ENABLE_CAMERA=0`，不要求连接摄像头。当前交付已完成 RTL 仿真、综合、实现和 FPGA 下载。矩阵键盘、数码管、板载按键/开关、LED、蜂鸣器及 W25Q64 已完成实机验证；摄像头和 HDMI 尚未连接或实测。

## 外设接线

使用工程自带 `constraints/password_lock_system.xdc`，不要再叠加通用 IO 约束。

| 外设 | 信号 |
|---|---|
| 系统时钟 | `Y18`，50 MHz |
| J2 矩阵键盘行输入 | `V2,R3,R2,W2`（P2IO[4:7]） |
| J2 矩阵键盘列输出 | `T3,T1,U1,U2`（P2IO[0:3]） |
| OV5640 | SCL `F15`、SDA `F13`；D0..D7=`F14,F16,E17,C14,C15,E13,E14,E16`；PWDN `D16`、XCLK `D14`、VSYNC `D15`、HREF `B15`、RESET `B16`、PCLK `C13` |
| HDMI-B | TMDS P=`T14,W15,T16,V13`，N=`T15,W16,U16,V14`（前三路数据，末一路时钟） |
| W25Q64 | CS `M20`、HOLD `K13`、MISO `M13`、SCLK `K14`、WP `K17`、MOSI `L13` |

矩阵键盘的逐线对应关系见 `矩阵键盘接线说明.md`。键盘是无源触点，只接 R1～R4 和 C1～C4，不接电源与地。摄像头排线按模块丝印的 3.3 V/GND 方向插入；当前实板应将 SW5 拨上以接通蜂鸣器，数码管使用 SW6 档位。当前实板已确认 P20 蜂鸣器为高电平使能，与旧版开发板手册中的低电平描述不同，工程以实测极性为准。

暂不使用摄像头时保持默认参数即可。需要启用时运行 `scripts/run_all.ps1 -EnableCamera`；该开关会把 `ENABLE_CAMERA=1` 传给顶层。关闭时摄像头初始化、采集和四帧 BRAM 会在综合时被移除，摄像头控制脚保持安全静止状态。

## 操作流程

默认密码为 `1234`。拨动 SW1 产生上升沿进入输入，数字键输入密码，`A` 确认，`B` 退格，`C` 取消。输入不足四位或超过四位时不会误确认。未开锁状态连续 8 秒无操作自动返回待机；开锁后 16 秒无操作自动上锁，开锁期间按 `A` 也可立即上锁。

连续输错三次会短暂显示 `Err1`、`Err2`、`Err3` 并允许重试；第四次错误立即进入 `ALAr`，报警 LED 以约 2 Hz 闪烁，蜂鸣器输出约 2 kHz 音调并同步间歇鸣叫，并在启用摄像头时抓取四帧图像。报警状态只有板载 KEY2 能解除，矩阵键盘和其它按键均不能停警。管理员按 KEY2 处理报警后，错误次数清零、矩阵键盘扫描器复位，并直接开始新的四次输入机会，无需重新拨动 SW1。8 秒无操作后仍会按题目要求回到等待。解除报警不会清除已捕获图像，HDMI 继续显示四宫格。

管理员改密：先将 SW1 拨上进入工作状态，再按 KEY1 进入 `SEt`，输入四位新密码后按 `A`。系统完成 W25Q64 擦除、写入和回读校验后才启用新密码；失败时保留旧密码并显示 `FErr`。两份日志记录支持掉电恢复，均无效时回退 `1234`。

数码管右侧显示输入数字，左侧显示 `PASS`、`SEt`、`ErrN`、`OPEN`、`ALAr`、`SAVE` 或 `FErr` 等状态；LED 分别表示就绪、输入、开锁和报警/故障。

## 验证边界

`sim/` 下提供锁控制器、报警蜂鸣器、键盘扫描、数码管、四帧采集、HDMI 渲染和 W25Q64 日志模型测试。Vivado 批处理在 Windows 上可能在测试 `$finish` 后停留数十秒，这是 XSim 2023.2 的退出行为，不代表测试失败；以日志中的 `PASS tb_*` 为准。已完成的实机项目和仍待验证的摄像头/HDMI 边界见 `实机验证报告.md`。
