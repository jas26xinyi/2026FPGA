# FPGA 密码锁系统使用手册

## 工程与下载

目标器件为 HX7A75A（`xc7a75tfgg484-2`），Vivado 2023.2 工程位于 `vivado/password_lock_system.xpr`。可直接下载 `password_lock_top.bit`；重新构建时在 Vivado Tcl Console 执行 `source scripts/build_all.tcl`。

当前交付已完成 RTL 仿真、综合和实现文件；摄像头、Flash、蜂鸣器及 HDMI 的实机连线尚未在本机验证。

## 外设接线

使用工程自带 `constraints/password_lock_system.xdc`，不要再叠加通用 IO 约束。

| 外设 | 信号 |
|---|---|
| 系统时钟 | `Y18`，50 MHz |
| J2 矩阵键盘行 | `T3,T1,U1,U2` |
| J2 矩阵键盘列 | `V2,R3,R2,W2` |
| OV5640 | SCL `F15`、SDA `F13`；D0..D7=`F14,F16,E17,C14,C15,E13,E14,E16`；PWDN `D16`、XCLK `D14`、VSYNC `D15`、HREF `B15`、RESET `B16`、PCLK `C13` |
| HDMI-B | TMDS P=`T14,W15,T16,V13`，N=`T15,W16,U16,V14`（前三路数据，末一路时钟） |
| W25Q64 | CS `M20`、HOLD `K13`、MISO `M13`、SCLK `K14`、WP `K17`、MOSI `L13` |

摄像头排线按模块丝印的 3.3 V/GND 方向插入；蜂鸣器使用 SW5 接通档，数码管使用 SW6 档位。

## 操作流程

默认密码为 `1234`。拨动 SW1 产生上升沿进入输入，数字键输入密码，`A` 确认，`B` 退格，`C` 取消。输入不足四位或超过四位时不会误确认。未开锁状态连续 8 秒无操作自动返回待机；开锁后 16 秒无操作自动上锁，开锁期间按 `A` 也可立即上锁。

连续输错三次会短暂显示错误编号并允许重试；第四次错误立即点亮报警 LED、启动蜂鸣器并抓取四帧图像。报警状态只有板载 KEY2 能解除，矩阵键盘和其它按键均不能停警。解除报警不会清除已捕获图像，HDMI 继续显示四宫格。

管理员改密：按下 KEY1 进入设置，输入四位新密码后按 `A`。系统完成 W25Q64 擦除、写入和回读校验后才启用新密码；失败时保留旧密码并显示 `FErr`。两份日志记录支持掉电恢复，均无效时回退 `1234`。

数码管右侧显示输入数字，左侧显示 `PASS`、`SEt`、`ErrN`、`OPEN`、`ALAr`、`SAVE` 或 `FErr` 等状态；LED 分别表示就绪、输入、开锁和报警/故障。

## 验证边界

`sim/` 下提供锁控制器、键盘扫描、四帧采集、HDMI 渲染和 W25Q64 日志模型测试。Vivado 批处理在 Windows 上可能在测试 `$finish` 后停留数十秒，这是 XSim 2023.2 的退出行为，不代表测试失败；以日志中的 `PASS tb_*` 为准。实机使用前请逐项核对键盘方向、摄像头供电、HDMI-B 和 SW5/SW6 档位。
